
# 🛡️ FraudShield AI

### AI-Powered Financial Fraud Detection System

## Project Overview
FraudShield AI is a Machine Learning application designed to identify potentially suspicious financial transactions.

It uses a Random Forest Classifier to analyze transaction patterns and estimate fraud probability.

## Features
- Interactive financial dashboard
- AI-based fraud detection
- Transaction risk probability
- Transaction history
- Normal and suspicious transaction filters
- Data visualization
- CSV download

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Machine Learning Algorithm
Random Forest Classification.

## Installation

1. Clone or download this repository.
2. Open the project folder in a terminal.
3. Create a virtual environment:

   python -m venv .venv

4. Activate it on Windows:

   .venv\Scripts\activate

5. Install dependencies:

   pip install -r requirements.txt

6. Run the application:

   streamlit run app.py

## Dataset
The project uses 2,500 synthetically generated financial transactions.

## Disclaimer
This is an educational prototype using synthetic data. Its predictions are not validated for real-world banking or financial decisions.
